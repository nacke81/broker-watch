# Broker Watch

Rung 4 of the NE Build System Program. Weekly check of people-search sites for listings of Mike; records found / not found / couldn't check per site, links the opt-out page. Read-only: Mike sends opt-outs himself.

**Phase 1 prototype:** fake person, fake results, localStorage only. https://nacke81.github.io/broker-watch/

`npm test` runs the status rules, including golden 3 (couldn't check is never not found).
